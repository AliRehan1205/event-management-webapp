# Event Horizon - Event Management Web App

## Overview

Event Horizon is an interactive event management web application developed using HTML, CSS, and JavaScript. The application allows users to view, add, search, sort, and delete events dynamically.

## Features

* Display upcoming events
* Add new events dynamically
* Delete existing events
* Search events by name or date
* Automatic event sorting by date
* Highlight past events
* Responsive design for desktop, tablet, and mobile devices

## Technologies Used

* HTML5
* CSS3
* JavaScript
* GitHub Pages
